# MSc CAVE — Animation Software Engineering

This repository contains my weekly coding exercises, coursework, experiments, and notes for the **Animation Software Engineering** module as part of the **MSc Computer Animation and Visual Effects (CAVE)** programme at **Bournemouth University**.

## About

The repository documents my progress throughout the module, with each week containing the code and exercises completed during classes and independent study.

The focus is on developing software engineering and programming skills relevant to **computer animation, graphics, VFX, and technical development**.

## Purpose

This repository serves as:

- A record of my weekly progress throughout the module
- A central location for coding exercises and experiments
- A reference for concepts covered during the MSc
- A space to experiment with animation and graphics programming beyond the required exercises
